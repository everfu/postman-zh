# 兼容性与验证边界

这里记录已取得的证据，不把结构检测当作实机验证。

## 环境矩阵

| 环境 | 已验证 | 尚未验证 |
| --- | --- | --- |
| macOS Apple Silicon / Postman 12.26.1 | 安装、整包备份、重复安装、完整恢复、签名、本地轻量客户端 | 所有第三方插件组合 |
| 同版本登录界面 | 常规/主题/快捷键设置布局、语言往返、原生菜单、重启保留、导航、请求选项卡、AI 固定提示 | 组织管理、计费、所有协作与团队功能 |
| 10.x / 11.x / 其他 12.x | 安装前验证归档、主入口和 preload 结构 | 每个版本的原生启动与远程界面 |
| Intel Mac | 代码无架构专用依赖 | 实机启动、签名、内置运行环境 |
| Linux CI | 语法、词典、文档、ASAR、DOM、回滚等自动检查 | 修改应用；本项目不支持在 Linux 安装 |

不支持 Windows、Linux 安装和浏览器扩展。更早架构、缺少 `app.asar`、无法识别的入口或不支持的版本会拒绝安装。

## 检查的含义

- **自动检查**：官方 ASAR 工具互读、完整性、替换失败回滚、设置结构、语言保存、fetch/XHR 和非目标请求透传、用户输入保护、固定控件与占位提示。
- **发布包检查**：解压后文件摘要、版本、执行权限、许可、备份说明，以及不夹带应用、依赖目录或本机账号资料。
- **人工运行验证**：本机启动应用并检查实际界面与语言切换。远程 Postman 界面可独立更新，后续版本需要再次回归。

CI 使用模拟归档与 DOM，不包含 Postman 程序，也不会安装或修改真实应用。CI 通过不能证明所有 Postman 版本都兼容。

## 已解决的回归

- 设置中的语言控件曾插入左侧导航的横向容器，导致导航逐字换行与正文重叠；现在只挂载到已识别的右侧正文列。
- 图标导航与新的请求选项卡存在固定文案漏译；现按控件范围补译，保留用户创建的请求标签与集合名称。
- AI 输入框的辅助标签与可见占位提示由不同节点绘制；两者分别处理，并验证编辑内容未被改写。
- macOS 原生菜单必须在构造前翻译；偏好变更后重建菜单，不能仅改已经创建的菜单项标签。
- 恢复原版不应依赖翻译文件；当前恢复路径独立于词典加载。

## 仍需注意

翻译覆盖不完整时保留原文。应用升级、官方 DOM 或语言包路径变更，可能导致部分补译或语言控件暂时失效；未知设置布局不会猜测插入位置。请通过[问题模板](https://github.com/everfu/postman-zh/issues/new/choose)提供版本和脱敏后的复现步骤。
