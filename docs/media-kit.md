# 项目介绍与素材

仓库：[everfu/postman-zh](https://github.com/everfu/postman-zh) · 下载：[最新版本](https://github.com/everfu/postman-zh/releases/latest)

## 简短介绍

**中文**

Postman ZH 是面向 macOS 的非官方 Postman 中文界面工具。支持一键安装、设置内切换语言、完整应用备份和一键恢复，让日常 API 调试继续使用熟悉的工具。

**English**

Postman ZH is an unofficial Chinese UI tool for Postman on macOS. It provides a local language switch, a full application backup, and a clear restore path while preserving your requests and collections.

## 一句话

熟悉的工具，中文的界面。

Chinese UI. Local choice. Full restore.

## 发布介绍

Postman ZH 现已作为独立项目开源。

为 macOS Postman 加入简体中文，在应用设置中选择中文或跟随官方语言。安装前备份完整应用，需要时可恢复原版及其签名。工具保留请求、集合名称与编辑内容，翻译随下载包提供。

目前已在 Apple Silicon / Postman 12.26.1 上进行实际验证，其他版本的验证范围请查看仓库。它是非官方本地修改，会改变应用签名；安装前请阅读使用说明。

源码、使用指南与下载：https://github.com/everfu/postman-zh
