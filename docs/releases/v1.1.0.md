# Postman ZH v1.1.0

Postman ZH 首次作为独立项目发布：为 macOS Postman 提供中文界面、设置内语言切换、完整备份与原版恢复。

## 下载与使用

- `postman-zh-macos.zip`：解压整个文件夹，保存 Postman 中的工作后双击 `postman-zh.command`。
- `postman-zh-media-kit.zip`：项目标识、封面、社交预览、设置示意与介绍文案。
- `SHA256SUMS`：同一版本两个 ZIP 的 SHA-256 校验值。

恢复原版可双击 `恢复原版.command`。使用指南位于下载包中，也可在仓库 `docs/installation.md` 阅读。

## 验证边界

已在 Apple Silicon / Postman 12.26.1 上实际验证本地与登录界面、设置布局、中英文切换、原生菜单、重启保存和完整恢复。自动检查覆盖 ASAR、DOM、网络透传、用户内容保护和失败回滚；CI 不安装真实 Postman。

其他 10.x/11.x/12.x 仅做结构检测，Intel 尚未实机验证。远程界面会随 Postman 更新，翻译不保证 100% 覆盖。
